# DOC-5: Серийные папки: шаблон и индекс

## Для агента

В папке с серией однотипных документов (`docs/adr/`, `docs/design-notes/` и т. п.) обязательны `template.md` и индекс (`ADR-INDEX.md`, `DN-INDEX.md`).
Новую серию без шаблона и индекса не заводи. Добавил документ в серию — обнови индекс.

## Зачем

Серия без шаблона и индекса расползается по форматам.

## Как проверяется

Тест индекса ADR в проекте; для остальных серий — на ревью.

## Исключения и особенности проектов

Нет.
