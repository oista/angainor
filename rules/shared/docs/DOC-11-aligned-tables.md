# DOC-11: Таблицы выровнены

## Для агента

Таблицы GFM пиши с колонками, выровненными по самой широкой ячейке; не оставляй «сжатые» разделители без пробелов.
После массовых правок запускай `mdformat docs/`, если он есть в проекте.

## Зачем

Правило из `docs-conventions` ENTAN и Clavis и Norma. Косметическое, поэтому режим по файлам.

## Как проверяется

Проверки нет. Если в проекте `mdformat --check` стоит в pre-commit, правило выключают (причина — этот pre-commit).

## Исключения и особенности проектов

Нет номера в каноне: предлагается добавить как DOC-11.
