# LAY-1: Корень репозитория — только по воротам

## Для агента

Не создавай новые каталоги в корне репозитория без явного согласия пользователя и прохождения ворот проекта: {{gate}}.
Новый код клади в существующий пакет нужного слоя.
В корень не клади временные и отладочные файлы (`cookies*.txt`, `*.html`, отчёты, выгрузки); `logs/`, `eval_output/`, `reports/` не коммить.
Допустимый корень: {{allowed_root}}.
{{boundaries}}

## Зачем

Корень быстро зарастает; каждый новый каталог — решение об архитектуре.

## Как проверяется

Проверки нет в реестре; в PRODATA есть `scripts/check_repo_hygiene.py`. Цель — проверка по списку из параметра `allowed_root`.

## Исключения и особенности проектов

Параметры: `gate` — что нужно сделать для нового каталога, `allowed_root` — список разрешённых каталогов, `boundaries` — границы с другими репозиториями.
