# AGT-8: Перед коммитом и PR

## Для агента

Перед созданием коммита или PR:
1. README: версия и разделы «Что это», «Как запустить», «Как тестировать» соответствуют коду.
2. Changelog: краткая запись об изменении{{changelog_note}}.
3. Новый публичный термин — в модель или глоссарий (DOC-4); архитектурный выбор — ADR.
4. Локально прогони проверки: `{{check_command}}`; PR с красными проверками не открывай.
5. В описании PR: что и зачем, ссылка на ADR (если есть), {{task_link}}.
{{eval_note}}
{{extra}}

## Зачем

Единый чек-лист вместо трёх разных разделов «Подготовка commit/PR» в `workflows.md`.

## Как проверяется

Пожелание; чек-лист дублирует шаблон PR проекта.

## Исключения и особенности проектов

Параметры задают проектные команды, пути и особенности.
