# AGT-1: Порядок прав источников

## Для агента

При расхождении текстов права, по порядку: 1) Accepted ADR в `docs/adr/`; 2) нормативные документы и схемы проекта; 3) код.
Черновики, планы (`.cursor/plans/`, `docs/plans/`), записи диалогов и архивные документы не описывают текущее состояние.
Если документ расходится с Accepted ADR, исправляй документ.
{{extra}}

## Зачем

Без порядка правоты агент при противоречии выбирает источник случайно.

## Как проверяется

Вручную на ревью; в moex-data-model порядок записан в `AGENTS.md`.

## Исключения и особенности проектов

Параметр `extra` — дополнения проекта (например, какие каталоги тоже считаются архивом).
