# AGT-10: PR маленький и про одно

## Для агента

PR должен быть про одно изменение: до 1000 изменённых строк и 50 файлов, не считая lock-файлов и сгенерированного. Большую работу режь на серию PR (см. AGT-7): сначала подготовка, потом поведение, потом уборка.
Схема данных и миграция данных идут разными PR. Если разбить действительно нельзя, скажи об этом пользователю и добавь в коммит `Large-Change: <причина>`.

## Зачем

Человек не читает код, он принимает результат. Большой PR нельзя проверить даже по тестам и сводке: он прячет побочные изменения.

## Как проверяется

`tools/check_pr_size.py --range origin/main..HEAD` в CI (стадия `guard`): считает строки и файлы диапазона без lock-файлов и сгенерированных проекций; выше порога блокирует PR, пока нет `Large-Change:`.

## Исключения и особенности проектов

Пороги по умолчанию (1000 строк, 50 файлов) заданы в инструменте; проектные пороги пока не поддерживаются.
