# AGT-7: Серия PR: одна тема на PR

## Для агента

Когда план задаёт серию PR-0…PR-N:
1. Одна тема на PR: пока делаешь PR-K, меняй только файлы его критериев приёмки, не трогай пути других PR.
2. Доставляй отдельными ветками или коммитами, а не одним деревом «всё готово». Зелёная проверка итогового дерева не доказывает промежуточные состояния — проверяй каждый PR отдельно.
3. PR-0 и шаги «инвентаризация/ADR» не трогают схемы и `generated/`, если план так говорит.
4. Не пропускай окно депрекации: сначала версия A (устарело), затем B (удаление).
5. Изменение схемы и миграция данных — разными коммитами.
6. Готовый прототип целиком архивируй (`wip/…`) и режь заново с чистой базы.
{{exceptions}}
Указания пользователя или плана главнее этих правил.

## Зачем

Перенос `multi-pr-series` moex-data-model; исключения проектов вынесены в параметр.

## Как проверяется

Пожелание.

## Исключения и особенности проектов

`exceptions` — документированные исключения проекта (например, финальный PR удаления в moex-data-model по ADR-048 и ADR-049).
