# Реестр правил для агентов

Источник истины для инструкций ИИ-агентам во всех проектах экосистемы. Решение — [ADR-0003](../docs/adr/ADR-0003-rules-registry.md) (Accepted).

Канон ([docs/canon/](../docs/canon/README.md)) отвечает на вопрос «что должно быть верно в проекте». Реестр — «как действует агент»; каждое правило ссылается на нормы канона (`norm`) и на проверку (`check`).

## Устройство

| Где | Что |
| --- | --- |
| [template.md](template.md) | шаблон правила |
| `shared/<область>/` | правила для всех проектов: `agent/`, `docs/`, `layout/`, `vcs/` |
| `projects/<проект>/project.yaml` | профиль проекта: что включено, режим, параметры, версия Angainor |
| `projects/<проект>/rules/` | правила одного проекта |
| `RULE-INDEX.md`, `RULE-MATRIX.md`, `projects/<проект>/RULES.md` | наглядные страницы, будут генерироваться |

Форматы: [rule.schema.json](../schemas/rule.schema.json) (шапка правила), [project-profile.schema.json](../schemas/project-profile.schema.json) (профиль).

## Как добавить правило

1. Скопировать `template.md` в нужную папку, дать идентификатор (`AGT-N` или `проект.ОБЛАСТЬ-N`), статус `Proposed`.
2. Написать раздел «Для агента» коротко; обоснование — в «Зачем».
3. Указать `norm` (если правило воплощает норму канона) и `check` (если нарушение ловит проверка).
4. Включить правило в профиле нужных проектов.
5. Правило, меняющее поведение проектов, меняется через PR с ADR; мелкие правки текста — обычным PR.

## Режимы и переключатели

- `always` — в контексте всегда (склеивается в один файл, ограничен бюджетом токенов проекта);
- `globs` — подключается при работе с файлами по шаблону;
- `on_request` — по фразам-триггерам.

Профиль проекта может выключить правило (`enabled: false`, нужна `reason`) и сменить режим. Правило с `norm` без `waiver: ADR-…` выключить нельзя.

## Команды

```bash
pip install pyyaml jsonschema           # один раз
python scripts/check_rules.py           # проверка реестра (--repos-root PATH: ещё check и waiver в проектах)
python scripts/build_rules.py           # страницы реестра: RULE-INDEX, RULE-MATRIX, RULES.md проектов
python scripts/build_rules.py --projections --repos-root PATH   # файлы в репозиториях проектов
python scripts/build_rules.py --check   # проекции совпадают с реестром (для CI)
```

Реестр пока без правил: перенос существующих правил — следующая фаза. Не реализовано: `.cursor/hooks.json`, запрет рукописных `.mdc` вне реестра.
